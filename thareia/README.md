# Thareia — the next Aethermoor game (design space)

This folder is the planning space for a new version of the Aethermoor game, built on the real campaign canon instead of the
original 17-location map. It lives on its own branch (`claude/tender-babbage-4wiplk`) so it never touches the branch where
the current game is being finished (`claude/cool-ptolemy-uc93gg`).

**Rule for this folder: design before we build.** No game code goes here until the design documents are agreed.

| Path | What it is |
|---|---|
| `lore/thareia-aethermoor-lore-compendium.md` | The lore compendium, as supplied. The source of truth for the world. Its canon tags ([LOCKED], [REFERENCE], [PLAYED], [LEGACY]) decide how firm each fact is. |
| `design/00-starting-point.md` | Where we are: how the current game relates to the canon, what it can lend the new game, and the design questions to settle first. |

The current game's code, art pipeline and assets are on `claude/cool-ptolemy-uc93gg` under `game/` and `art-in/`. The new
game may reuse them, but copies come over only once the design says what is needed.
