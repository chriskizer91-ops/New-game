AETHERMOOR — SIX CONTINUOUS MAP TILES

Six native-resolution 512 x 512 PNG images form one 1536 x 1024 map.
The artwork was newly generated using the supplied continent as the main
geography reference and the interactive map as a regional-detail reference.
Each tile was extracted without resizing from the same continuous painting.

ASSEMBLY ORDER
Top row, left to right: 01 Northwest; 02 North Center; 03 Northeast.
Bottom row, left to right: 04 Southwest; 05 South Center; 06 Southeast.

Place tiles directly adjacent with zero gap and zero overlap. Do not stretch
individual tiles differently. The assembly.json file gives exact coordinates.
Aethermoor-Complete-Map.png is the full painting, included for reference.

FOR GAME INTEGRATION
Use the JSON coordinates as image-space positions. The six tiles reconstruct
the complete image pixel for pixel. At fractional display scales, draw them on
one canvas or align edges to avoid browser rounding gaps. These tiles join only
in the supplied layout; their exterior edges are not repeating textures.

This is a new illustration, not a pixel-registered replacement for the old
HTML background. Reposition existing clickable markers against the new art.
Small settlements and terrain details are illustrative; the source HTML's
location descriptions remain the reference for named locations.

RESOLUTION
The image generator returned 1536 x 1024 pixels. These are its native pixels,
not an artificially enlarged higher-resolution export. The six tiles each
show a closer section of the same newly painted continent.

GENERATION
Created with the built-in image-generation tool; the full prompt is included
in GENERATION-PROMPT.txt. Mechanical PNG extraction created the six tiles.
