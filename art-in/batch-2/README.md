# Finished batch 2 paintings go here

Upload the paintings from `art-requests/batch-2.md` into this folder (Add file → Upload files), named
exactly as that page says: `map-hearth-road-a.png`, `map-fawnrest.png` and so on. A long road's two
panels are `-a` and `-b`. Extra tries get a number after the name: `map-fawnrest-2.png`. A zip of
them is fine too. You don't need to send them all at once: every map whose pictures are here goes
into the game.
