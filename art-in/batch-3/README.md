# Finished batch 3 paintings go here

Upload the paintings from `art-requests/batch-3.md` into this folder (Add file → Upload files), named
exactly as that page says: `map-rotbridge.png`, `map-murkway-a.png` and so on. A map too big for one picture
comes as panels `-a`, `-b` (and `-c` for the long boardwalk). Extra tries get a number after the name:
`map-bogmire-2.png`. A zip of them is fine too, or send them in the chat. You don't need to send them all at
once: every map whose pictures are here goes into the game (`tools/paint-import.mjs --batch`).
